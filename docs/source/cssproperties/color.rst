color
=======

Wxcss supports multiple kinds of color specifiers. They support whatever cssutils supports.

.. admonition:: Important

    :code:`color` applies the `ForegroundColor` property to a window.

How To Use
------------


.. code-block:: css

    Notebook {
        color: #FF80FF;
    }

    TextCtrl {
        color: #8090FF;
    }

    StaticText {
        color: #FFFFFF;
    }
