background-color
==================

Wxcss supports multiple kinds of background-color specifiers. They support whatever cssutils supports.


How To Use
------------


.. code-block:: css

    Notebook {
        background-color: #FF80FF;
    }

    TextCtrl {
        background-color: #8090FF;
    }

    StaticText {
        background-color: #FFFFFF;
    }
