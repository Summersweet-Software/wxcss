border-width
==============

The :code:`border-width` property works by setting the border-property of the window's corresponding size-item. 
It currently only supports :code:`px` units.


.. admonition:: Warning

    This is mostly work-in-progress and may change a little as time goes on.

How To Use
------------

.. code-block:: css

    TextCtrl {
        border-width: 10px;
    }
